Схема 15, модель ABI v6, плагины v2. Свежий verify 8 tooling/301 Rust/85 Swift; feature Swift 130, сборка, подписи, аудит и ревью PASS. Принят локально 24B: Google Диск и Документы через локальный `workspace-mcp` ([ADR-022](docs/decisions/0022-local-mcp-servers.md)); живой пилот ждёт пользователя. Принят 17A: Todoist на общем движке интеграций (схема 16, verify 8/358/91). Новый интерфейс по дизайну пользователя ([ADR-023](docs/decisions/0023-ui-redesign-liquid-glass.md)) — в последнюю очередь. Настоящие подключения и UI ещё не проверены. [Текущий статус](docs/project-status.md), [отчёт 17A](target/verification/17a/handoff.txt).

Принят GitHub13A: выбранный PR и обсуждение → сохранение выбранных сведений в дело → постоянная помощь08B. Verify8 tooling/186 Rust/72 Swift, расширенный Swift111 и последующие точечные проверки GitHub прошли; сборка/подписи/ревью PASS. Настоящий доступ GitHub и UI ещё не проверены. Принят 10A: локальный голосовой ответ через Parakeet → редактируемый текст → отдельная отправка. Повторные проверки 20 октября: 105 Rust / 69 Swift, расширенный прогон 95 Swift, готовый helper без сети — 8/8. Настоящий микрофон, UI и live Fast ещё не проверены. [Отчёт](target/verification/10a/handoff.txt).

Принят08A: текущая помощь показывается в карточке у края экрана и общей панели; на уточнение можно ответить текстом через один общий черновик и одно подтверждение отправки. Verify105 Rust/51 Swift, feature Swift72, build/signature/review PASS. Фактические UI/focus/Spaces и live Fast ещё не проверены. [Договор08A](docs/decisions/0012-edge-card-and-text-reply.md).

Принят11A: явный выбор проекта и исключений → чтение метаданных локальных веток → сохранение выбранной ветки в дело → существующая помощь. Проверены99 Rust/50 Swift и отдельный feature-прогон65 Swift; app build/signature/review PASS. Это ручной путь, не автоматическое обнаружение забытых веток. [Договор11A](docs/decisions/0011-selected-local-branches.md).

Основа универсального помощника, который понимает текущую задачу и сохраняет контекст между приложениями.

**Общее ядро — Rust. Нативные оболочки — Swift/macOS и C#/Windows.** Реализована первая основа macOS: несколько дел, ручные заметки, явные связи, ручной план/зависимости/проверки, завершение с итогом и очисткой, исправление/удаление памяти и ручная пауза через Swift → C → Rust/SQLite. Собственный вход ChatGPT, сохранение сессии в Keychain, обновление/отмена/локальный выход реализованы и проверены локально. Добавлены меню с индикатором/паузой и кнопка локальной проверки прав без запроса доступа. Ручная помощь по сохранённому делу06F реализована и проверена локально; для её реального использования нужны собственное подключение и подтверждённый High Fast. Наблюдение и инициатива ещё не реализованы; настоящий native consent/refresh не подтверждён. Windows-оболочка ещё не реализована.

## Начало работы

06F добавляет точный preview выбранного сохранённого контекста, один High Fast запрос и обоснованный результат с защищённым копированием. Verify:8tooling/83Rust/48Swift; отдельный HTTP/SSE прогон8 tests, build/signature PASS. Это локальная проверка реализации, не подтверждение live Fast или полезности модели. [Договор06F](docs/decisions/0010-selected-task-assistance.md).

В06D добавлена нативная проверка подключения: один синтетический Luna Low Fast запрос, проверка фактического режима и постоянный учёт известного/неизвестного потребления. Локальные HTTP/SQLite/Swift проверки и сборка прошли; настоящий native Fast ещё не подтверждён. Диагностика не включает наблюдение или предложения. [Контракт и ограничения](docs/decisions/0008-native-chatgpt-connection-check.md).

На macOS с Node 22, Yarn 1, Rust (rustfmt + Clippy) и Swift 6:

```sh
yarn install --frozen-lockfile
yarn verify
```

На Windows для ядра и правил агентов:

```sh
yarn install --frozen-lockfile
yarn verify:portable
```

Сборка приложения: `yarn build:macos`. Результат — `target/macos/Build/Products/Debug/Ambient.app`. Нужен официальный Rust 1.99.1 с библиотекой, совместимой с macOS 26 (приложение требует macOS 26+, D72); воспроизводимая изолированная установка описана в [macOS README](src/platforms/macos/README.md). Точные команды и ограничения: [разработка](docs/development.md), [текущий статус](docs/project-status.md).

## Структура

```text
agent-sources/        исходники правил, ролей и общих навыков
.agents/skills/       неизменённый процесс планирования Matt
src/core/            единое ядро Rust
src/platforms/macos/ нативный модуль Swift
src/platforms/windows/ место для нативной оболочки C#
src/bridge/          граница C ABI для обеих оболочек
src/providers/       границы подключения облачных и локальных моделей
src/replay/          место для воспроизведения сценариев ядра
tests/replay/        будущие обезличенные эпизоды и ожидания
docs/                продукт, архитектура, решения, разработка
scripts/             проверенный генератор инструкций
```

Обязательные правила находятся в `AGENTS.md` / `AGENTS.override.md` и scoped-файлах. Правки вносятся в `agent-sources`, затем выполняется `yarn agents:generate`. README описывают проект, а не заменяют инструкции.

Управление автозапуском06E реализовано: Settings читает системный статус, позволяет явно включить/выключить запуск при входе и перейти к подтверждению macOS. Своего постоянного флага и регистрации при каждом старте нет; ручная пауза сохраняется. Во время разработки системная регистрация и следующий login не проверялись. Полная интеграция первого включения помощника остаётся открытой.
