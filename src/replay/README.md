# Replay

Место будущего runner для одних и тех же core episodes на macOS и Windows. Сейчас runner отсутствует. Корпус хранится в `tests/replay`; требования к случаям — в [testing](../../docs/testing.md).

Replay использует управляемое время и события; live capture и платные provider tests выполняются отдельно.
