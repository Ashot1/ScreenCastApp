# Нативные платформы

macOS реализуется на Swift, Windows — на C#. Первая macOS-оболочка уже соединена с Rust core через C ABI для постоянной памяти; Windows ещё не реализована. Capture, разрешения, геометрия и исполнение принадлежат нативным оболочкам и добавляются отдельными рабочими срезами.

Платформенные возможности могут отличаться. Оболочки сообщают capability/completeness, а общее ядро выбирает поведение.
