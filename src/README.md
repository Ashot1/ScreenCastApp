# Исходный код

Текущий принятый пакет 24B (локальный объём): Google Диск и Документы через управляемый локальный `workspace-mcp` по ADR-022 — `ManagedServerId` и встроенный пакет в Core, рецепт, установка через `uv`, провод loopback HTTP и OAuth в providers (`managed.rs`, `managed_recipe.rs`, `oauth.rs`, `oauth_registry.rs`, клиент из `build.rs`), 21 экспорт `ambient_plugin.h` v2 в bridge, «Добавить Google» и вход в macOS; живой пилот ждёт пользователя. До него 24C (локальные серверы: `local_host.rs`, `Protocol<Wire>`, модель ABI v6) и 24A (слой плагинов по ADR-021). Ранее 23C: интеграции на общем движке и переключатели. Schema 15; memory3/auth1/source1/Codex1/model6, ABI интеграций v1 и плагинов v2.

`core` владеет памятью дел/планов/источников, постоянной лентой, проверками актуальности и учётом попыток. `bridge` переводит ограниченные C ABI и управляет буферами/handles. `providers` выполняет ChatGPT OIDC/PKCE, bounded Responses и ограниченные GET интеграций GitHub и Jira через общий транспорт. `platforms/macos` владеет native UI, Keychain, файловым чтением, системными разрешениями и отдельным Parakeet helper. `platforms/windows` пока содержит границы будущей C# оболочки; `replay` — описание без runner.

08B хранит один текущий диалог, включая атрибуцию вопроса модели и ответа пользователя, и все основания предложения. Обычное изменение делает помощь устаревшей; забывание, завершение и отзыв источника очищают зависимые производные атомарно. Native показывает те же объекты в краевой ленте и панели, сохраняя один независимый черновик. Copy/ответ требуют нового текущего допуска после restart.

11A читает явно выбранные локальные ветки;14A — ограниченное окно выбранного Codex JSONL. Сырой архив не сохраняется.10A распознаёт голос локально после окончания записи; редактируемый текст отправляется отдельно. Настоящий public WAV → helper → draft → локальный HTTP проверен вместе с08B.

Локальные проверки 24B: 8 tooling/331 Rust/90 Swift, feature Swift 136, bridge 33, Clippy/build/signatures/audit PASS. Реальные UI/микрофон/TCC, High Fast/качество смыслового сопоставления и Windows не подтверждены. Наблюдение и проактивные напоминания ещё не реализованы.
