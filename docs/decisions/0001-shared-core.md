# ADR-001: одно Rust-ядро и нативные оболочки

Статус: принято пользователем 17 октября 2026 года.

Требование: общий код поведения для macOS и Windows, нативная интеграция с рабочим столом. Пользователь выбрал «Rust — общее ядро, Swift/C# — оболочки».

Решение: Rust владеет памятью, планированием, routing, бюджетами и валидацией. Swift/macOS и C#/Windows владеют UI и системными адаптерами. Узкий C ABI — выбранное направление соединения; функции и lifecycle будут определены первым проверяемым срезом. Local inference изолирован отдельным helper process.

Альтернативы: Swift core переносим на Windows, но добавляет Swift toolchain в Windows shell; два нативных ядра дублируют правила и нарушают требование. Rust не выбран из-за обещанной скорости: замеров нет.

Последствия: CI ядра нужен на обеих ОС с начала работы. FFI имеет явное владение памятью и ошибки. Shell не может реализовать собственную копию domain policy. Пока ABI отсутствует, build пустого crate не считается доказательством interop.
