Принятый независимый пакет после06C — [06D: нативная проверка подключения](decisions/0008-native-chatgpt-connection-check.md). Каждый этап получает отдельную спецификацию и задачи через перенесённый Matt flow. Ниже порядок и критерии, а не автоматически разрешённая реализация всего продукта.

| Этап | Результат | Критерий готовности |
| --- | --- | --- |
| 0 — основа | Правила агентов, документация, Rust workspace, Swift package, CI | Генерация совпадает, tooling tests/build/lint выполнены; ограничения названы |
| 1 — bridge + observation/replay | Узкий C ABI, нативные события macOS, evidence/latest-state/edge log, loss accounting, память задачи | Синтетический round-trip; alert не теряется после смены окна; byte limits; replay одинаков на Windows/macOS |
| 2 — cloud baseline | Provider contracts, consent, deadline, ledger, прямой reasoning/structured route | Полный эпизод оценён человеком; стоимость и unknown usage учтены; нет скрытых retries |
| 3 — local shadow | Один helper/model candidate и supervisor | Warm/cold/memory/cancel-tail измерены; падение helper не задерживает cloud/UI; double cost ограничен |
| 4 — adaptive admission | Допуск local по классу, аудит отрицаний, rollback допуска | Доказанная польза на корпусе; thermal fallback не превышает деньги; учтены пропуски |
| 5 — native Windows + actions | C# shell, те же core/bridge contracts; ограниченные обратимые действия | Реальные capture/geometry tests обеих ОС, актуальные предусловия и postconditions |
