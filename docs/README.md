# Документация

Согласованное новое направление — [единый слой интеграций, ADR-019](decisions/0019-unified-integrations.md). D59 закреплял оркестратора и исполнителей в Claude Code. Для карточек 26E, 27E и 27F пользователь выбрал текущий чат Codex и отдельных исполнителей Codex (D105); Продолжение 26F → 27G согласовано в том же процессе Codex (D108); остальные решения этим исключением не меняются. Подключения делятся на интеграции и плагины (D60); контракт интеграций — [ADR-020](decisions/0020-integration-layer-contract.md).

[Продукт](product.md) объясняет, зачем нужен помощник. [Архитектура](architecture.md) — кто владеет решениями и данными. [Контракты](contracts.md) — как соединяются ядро, оболочки и модели.

[Статус](project-status.md) отличает существующие файлы от будущей реализации. [Этапы](roadmap.md) задают порядок разработки, [проверки](testing.md) — критерии результата. [Приватность](privacy.md) описывает границы данных и разрешений. [Разработка](development.md) содержит воспроизводимые команды.

[ADR](decisions/README.md) фиксируют решения, [источники](technical-references.md) — проверенные возможности платформ. [Исходные документы](reference/README.md) сохранены без изменения.

[Спецификация поведения помощника](features/assistant-behavior/spec.md) собирает согласованные требования первой личной версии; [журнал решений](features/assistant-behavior/decisions.md) сохраняет ответы пользователя и основания выбора. Непроверенные подключения в спецификации отмечены отдельно от готовых возможностей.

[22 задачи первой версии](features/assistant-behavior/issues/README.md) содержат согласованную разбивку, зависимости и критерии приёмки. По D56 основа 06 и память ADR-004/005 проверены; нативное подключение ADR-006 реализуется независимо от неподтверждённого Fast; последующие части открываются по проверенным используемым контрактам. Полная приёмка интеграций сохраняется. Фактический ход запуска отражён в [журнале выполнения](features/assistant-behavior/execution.md).
