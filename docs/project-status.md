Последний принятый пакет — **24B в локальном объёме: Google Диск и Документы через локальный `workspace-mcp`** ([ADR-022](decisions/0022-local-mcp-servers.md)): кнопка «Добавить Google», установка сервера через `uv` по закреплённым хэшам (около 250 MB, около 25 s), вход OAuth со встроенным клиентом, отзыв доступа при выходе, 8 разрешённых инструментов чтения. Ранее приняты 24C, 24A и 23A–23C. [Приёмка 24B](../target/verification/orchestration/24b-parent-inspection.md).

**Следующий фронт — Todoist 17A** (ADR-018, D65–D67): третий HTTP-адаптер движка интеграций и пятая встроенная интеграция. Живой пилот Google (24B) — когда пользователь включит Google Drive API и Google Docs API и даст согласие; проводит сам пользователь, исполнитель 24B направляет и проверяет. На этом Mac плагины через `npx` пока не работают: Homebrew-node сломан (нет `libllhttp`). С 21 октября проект — локальный git-репозиторий; оркестратор коммитит каждое принятое состояние.

С 20 октября разработкой управляет отдельный оркестратор — сессия Claude Code `024011b0-b1de-40d7-99bb-4a80905b488b` (Opus 5.5); подробности в [execution](features/assistant-behavior/execution.md). Прежний чат остаётся планировщиком, больше не создаёт агентов и не управляет волнами; его автоматизация `ambient` остаётся приостановленной. Исполнители — отдельные сессии Claude Code (D59).

Приложение уже хранит несколько дел, сведения, связи, ручные планы и итоги. Помощь по выбранному сохранённому контексту и постоянная лента проверены через настоящий локальный HTTP/SSE транспорт. **Наблюдение за работой и проактивный помощник ещё не реализованы.** Настоящий High Fast, собственный нативный consent, микрофон, UI, macOS 14 на устройстве и Windows остаются непроверенными.
