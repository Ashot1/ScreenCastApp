**Следующий фронт — выбирает пользователь** среди функциональных направлений: наблюдение за работой и проактивные предложения (06/09) или остальные встроенные интеграции (Gmail, Google Календарь, Apple Заметки и Напоминания). Новые исполнители без слова пользователя не запускаются (D79). Новый интерфейс macOS ([ADR-023](decisions/0023-ui-redesign-liquid-glass.md), задачи 25A–25H) — в последнюю очередь. Живой пилот Google (24B) ждёт пользователя. Нужно поправить давний тест голоса, чувствительный к нагрузке. На этом Mac плагины через `npx` не работают, пока не исправлен Homebrew-node. С 21 октября проект — локальный git-репозиторий; оркестратор коммитит каждое принятое состояние.

С 20 октября разработкой управляет отдельный оркестратор — сессия Claude Code `024011b0-b1de-40d7-99bb-4a80905b488b` (Opus 5.5); подробности в [execution](features/assistant-behavior/execution.md). Прежний чат остаётся планировщиком, больше не создаёт агентов и не управляет волнами; его автоматизация `ambient` остаётся приостановленной. Исполнители — отдельные сессии Claude Code (D59).

Приложение уже хранит несколько дел, сведения, связи, ручные планы и итоги. Помощь по выбранному сохранённому контексту и постоянная лента проверены через настоящий локальный HTTP/SSE транспорт. **Наблюдение за работой и проактивный помощник ещё не реализованы.** Настоящий High Fast, собственный нативный consent, микрофон, UI, macOS 14 на устройстве и Windows остаются непроверенными.

Новых генераций и Jev-вызовов нет. [Проверка официального маршрута Fast](features/assistant-behavior/evidence/01-fast-route-review-2026-10-20.md) не дала основания повторять тот же запрос.
