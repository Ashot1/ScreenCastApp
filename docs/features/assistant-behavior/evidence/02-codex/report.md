# 02 — Независимое чтение Codex

**Результат: PASS для проверенной области G1.** Дата: 2026-10-18.

Отдельный процесс Python прочитал настоящие сохранённые данные локальных тестовых чатов Desktop: исходный промпт, обычный текст плана, точную ссылку и завершение с идентификатором хода. Читатель не запускал Codex, не подключался к app-server/SQLite и не продолжал агента. Это проверка осуществимости, не реализация источника Ambient.

Область подтверждения: приложение **26.1013.40934 (20770)**, встроенный движок **0.163.0-alpha.10.2**, локальные `agent_created_thread` и один вручную начатый чат с `thread_source=user`, `history_mode=paginated`, только доступные записи выбранных файлов. Cloud, универсальное покрытие вручную созданных/импортированных чатов, будущие версии и полная история прежних страниц не объявлены поддержанными. Задача 02 снимает свою блокировку задачи 14 только в этой области; зависимость 14 от 07 сохраняется.

## Способ чтения и ограничения

[read_rollout.py](../../../../../tests/feasibility/02-codex/read_rollout.py) — самостоятельный тестовый инструмент без зависимостей. Он открывает один переданный файл в `rb`, читает не больше 16 MiB + 1 байт и отвергает превышение. Никакого перечисления всех чатов в читателе нет. Python API возвращает точный текст в памяти; CLI выводит размеры и SHA-256 вместо текста.

Принимается только движок `0.163.0-alpha.10.2`. Проверяются структура входа, совпадение thread ID, уникальность turn ID и привязка terminal marker. Неизвестные виды записей, изменённая версия, повреждённая полная строка, `compacted` вне `paginated`, завершение без известного начала или идентичности дают ошибку. В `paginated` известные compaction-записи подсчитываются согласно официальной проекции видимой истории; замещающий контекст не превращается в пользовательские сообщения. Последняя строка без перевода строки считается ещё не сохранённой; после дописывания терминального события повторное чтение замечает завершение.

`task_complete` с `error` означает неуспешное завершение, `turn_aborted` — прерывание. Прерывание без идентификатора не приписывается произвольному ходу. Ни mtime, ни отсутствие процесса, ни вычисленный другим сервером статус не используются как завершение.

Все проверенные пользовательские треды имеют `history_mode=paginated`. Файл не обещает полноту старых страниц. Здесь исходный промпт и нужные сообщения фактически присутствовали и были прочитаны. Восстановление более ранней отсутствующей истории потребует отдельной проверки; отсутствие текста не означает, что его никогда не было. Structured `Plan` в разрешённых записях отсутствует. Его разбор проверен синтетическим тестом, а настоящая доступность плана подтверждена обычным текстом сообщения. Восстановление каждого transient `update_plan` не обещается.

## Замер завершения и отсутствие записи

Наблюдатель увидел работающий ход ревьюера до появления terminal marker. Последнее чтение без завершения: `1792351020955402000` ns Unix. Первое чтение с полным marker: `1792351021245091000` ns. Событие имеет timestamp `2026-10-18T19:17:01.013Z`, первый результат чтения — примерно `19:17:01.245091Z`. Интервал между соседними чтениями **289.689 мс**, опрос настроен на **250 мс**. Завершение также соответствует фактически полученному результату обязательного ревьюера.

**232.091 мс — один замер event timestamp → наблюдение**, включающий задержку записи/доступности, опрос и чтение. Задержка от последнего модельного токена, максимальная задержка, нагрузка и распределение задержек не измерены. Системные часы не менялись в ходе пробы; это не метрологическая гарантия.

Попытки краткого наблюдения 05 завершились до его финала; следующий запуск уже увидел сохранённое завершение `19:11:51.226Z`. Поэтому по нему задержка не засчитывается. Наблюдение 04 остановлено после получения достаточного живого доказательства на ревьюере; `task_complete` для 04 не утверждается. [live-04.jsonl](live-04.jsonl) сохраняет только исходный снимок, [live-05.jsonl](live-05.jsonl) явно сообщает уже завершённый ход.

Проверка 05 до/после чтения дала SHA-256 `d755907df2105c35524f6543f72903178a1d77bebd85a2462764bef38aca69a2`; хеш прочитанного снимка совпал. Отдельно сняты размер и mtime_ns `state_5.sqlite`, WAL, SHM, `history.jsonl`, `session_index.jsonl`: в этом коротком интервале совпали. SQLite не открывалась. Эти наблюдения вместе с кодом `rb` подтверждают отсутствие записи выбранным читателем, но не утверждают отсутствие всех фоновых записей работающего Desktop или любого возможного изменения служебного профиля.

Получение версии CLI — отдельная диагностическая команда: CLI предупреждал о невозможности создать PATH aliases в ограниченной среде. Это не способ чтения истории. Второй app-server на профиле не запускался.
