## Что реализовано по D55

- Одна собственная generic-password запись file-based macOS Keychain. Swift Security helper выполняет только хранение; Node владеет входом, refresh и проверкой привязки. Service фиксирован, account определяется host UUID и полной проверенной регистрацией. `.local/installation.json` хранит только host UUID и `{client_id, issuer, subject}`, с правами 0600. Токенов в файлах, argv, env или logs нет.
- Действующий кэш используется без браузера. При его отсутствии вход использует известный issued client ID; initial dynamic registration разрешена только без регистрации. State/PKCE/nonce, callback, подпись RS256, issuer/audience/expiry и прежняя личность проверяются. Нужны права подписки и refresh token. Полная сессия сохраняется **до** model discovery и переживает его ошибку. Ошибка хранилища останавливает запуск без browser fallback. Неопределённая initial registration сохраняет `registration_pending`; уже проверенная привязка не теряется при отказе в scopes/refresh token.
- Истёкшая/почти истёкшая сессия обновляется одним `openid-client.refreshTokenGrant`. Старая запись успешно удаляется до сетевого запроса; новый access token, фактический `expires_in` и replacement refresh token проверяются и сохраняются до использования. Потеря ответа, плохой ответ или ошибка записи не повторяют запрос, не восстанавливают старый rotating token и не открывают браузер в этой попытке. Следующий запуск может войти с тем же issued ID; сетевая ошибка не объявляется доказанным отзывом доступа.
- Refresh отправляет только issued client ID, refresh token и resource, без scope/client secret/PKCE. Отсутствующий scope сохраняет прежние проверенные права; присутствующий ограничивает их. Optional ID token проходит библиотечную проверку подписи/issuer/audience и локальную проверку срока, прежнего subject и nonce, если он есть. `earliest_refresh_at` не используется. ID token/email не сохраняются; userinfo, CLI credentials и несколько аккаунтов не добавлены.
- Helper читает stdin ограниченным циклом, JSON ограничен 64 KiB, Keychain data — 48 KiB. Стабильный release binary собирается заранее. Возможен системный запрос доступа; ACL не расширяется. Timeout/overflow/Ctrl-C/stdin error завершают helper, а существующий `active.lock` удерживается до его `close`. На ACL-диалог отведено до 120 секунд.
