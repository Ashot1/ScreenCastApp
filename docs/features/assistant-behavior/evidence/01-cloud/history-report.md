# 01 — Облачный анализ: проверка осуществимости

Дата: 2026-10-18. **Текущий итог: BLOCKED.** Пользователь выбрал подписку ChatGPT вместо отдельно оплачиваемого API. Предложенные $20 OpenAI не одобрены; платный API запускать нельзя. Сохранённый вход Codex CLI проверен: **logged_in=true, login_type=chatgpt**. Inference не запускался. G5 и задача 06 остаются заблокированы до адаптации и настоящих проб.

## Текущее уточнение способа подключения

Уточнение человека прочитано через read_thread в управляющем чате, turn `01a15098-1e11-7853-9264-31f3a56e1e78`. По поручению управляющего на этом ходе изменяются только документы и статус; код стенда не переписывается.

Выполнен `/opt/homebrew/bin/codex login status`. stdout/stderr захвачены в память обёрткой; выведены только наличие входа, тип входа и отсутствие inference. Сырой вывод, токены и auth.json не сохранялись и напрямую не читались; вход и настройки аккаунта не менялись. [Обезличенный результат](auth-availability.json).

Наличие CLI-входа снимает прежний вопрос «есть ли сохранённая авторизация ChatGPT у Codex». Оно не доказывает остаток квоты, успешный анализ текста/изображения, право передать этот вход другому приложению или native-интеграцию Ambient. Код HTTP-стенда, его prepared-запросы и денежная формула сохранены без изменений как история прежней проверки; живые запуски этого стенда запрещены новым поручением.

Минимальный вариант стенда: заменить платный HTTP-транспорт одним `codex exec` с принудительным ChatGPT-входом, существующими синтетическими входами и конечной JSON-схемой; разбирать события CLI, убрать из активного пути API-ключ/долларовые ставки/старый Omax, запретить автоматические повторы и платный fallback. Это пока предложение; код не изменён. До inference остаётся проверить режим без инструментов и дополнительных кредитных списаний. [Подробности и границы](runbook.md).

Для настоящего native-подключения Ambient документирован собственный Sign in with ChatGPT для личных локальных приложений. Он требует отдельной регистрации и человеческого согласия в браузере; CLI-вход это не заменяет. В прямом маршруте обязательны store:false/stream:true, max_output_tokens недоступен. Прежняя формула резерва не переносится на подписку. Runtime Rust/Swift сохраняется. Применимый результат External Researcher родителя использован повторно; уже вызванный специалист дополнительно подтвердил именно ограничения SIWC без inference и чтения секретов. Первичные ссылки приведены в runbook.md.

До согласования адаптации, собственного согласия приложения и настоящих проб статусы реальных модельных проверок остаются BLOCKED. API-ключ и отдельный долларовый лимит OpenAI больше не являются предложенным способом разблокировки. На этом ходе не повторялись модельные, сборочные и ранее завершённые локальные тесты: изменены документы/статус и выполнена только проверка наличия авторизации.

## Что сделано

- Перепроверены первичные источники кандидата: [факты, ставки, формула и ограничения](history-sources.md).
- Подготовлены семь синтетических случаев, схема ответа и PNG без личного контекста. [Материалы](../../../../../tests/feasibility/01-cloud/cases.json), [инструкция воспроизведения и будущего запуска](runbook.md).
- Написана отдельная утилита одной пробы. По умолчанию она не использует сеть. Без ключа, заданных лимитов, согласия на синтетические данные и актуальной даты тарифа отправка запрещена.
- До запроса синхронизируется отдельный резерв; исключён одновременный запуск. Ошибка/отмена/неизвестный usage удерживают резерв, включая следующий запуск. Повреждённые записи, смена настроек или месяца запрещают продолжение.
- Локальные тесты проверяют расчёт с кэшем и длинным контекстом, разбор внешнего ответа, основание по известному source ID, корректное молчание, отказ, неполный и неверный ответ. Они используют явно тестовые ответы и не доказывают работу модели.

## Проверенная конфигурация эксперимента

OpenAI Responses, фиксированный общий endpoint, Standard (`service_tier=default`), `gpt-6.1-sol`, reasoning low, `store=false`, foreground, пустой список tools, строгая JSON Schema, автоматическая обрезка выключена. Только текст и собственный PNG; аудио, Files API, фоновые агенты, внешние инструменты и цепочки fallback не используются. [Опорные первичные документы](history-sources.md).

Из опубликованного потолка входа и дорогой ставки записи кэша выведен консервативный резерв **$5.280720** для выхода ≤2048 токенов и **$5.250240** для выхода ≤16. Это верхний резерв, не ожидаемая цена короткого запроса и не установленный лимит. Он покрывает обе тарифные ветки выбранного режима. Токены рассуждения не считаются второй раз. Предварительный count не вызывается: его бесплатность не установлена.

Настройки по шаблону намеренно null/false. Дата тарифа закреплена в коде и проверяется перед живым запуском. Будущая дата требует повторной проверки тарифов; смена модели/режима/endpoint требует нового доказательства стоимости. Варианты с надбавками не включены. Индивидуальный договор, налоги, конвертация валют и фактический billing не исследованы.

Ключ для разовой утилиты принимается из `OPENAI_API_KEY` в память подпроцесса. Постоянное системное хранение ключа в Keychain, требуемое продуктом, не реализовано этим пакетом. Неизвестный идентификатор записи Keychain не угадывался. Условия `store=false`, abuse logs, кэша и исключений изображений описаны в источниках; локальное удаление не обещает удаления у провайдера.

- TDD: первоначально 15 тестов упали на отсутствующей логике, затем 16 прошли. Ревью выявило порядок предупреждения 80%; отдельный новый тест воспроизвёл ошибку до исправления. После исправления **17/17 PASS**. Предупреждение выводится до transport после сохранения резерва. Ревьюер повторно проверил только это исправление и выполнил узкий тест: PASS.
- `yarn verify`: agents:check PASS, test:tooling PASS (8), check:core PASS, lint:core PASS, test:core PASS (0 поведенческих тестов). Swift build BLOCKED средой: `sandbox-exec: sandbox_apply: Operation not permitted` при обработке существующего manifest. Полный verify завершился кодом 1 и **не прошёл**. Общие настройки не изменялись.
- Отдельный `yarn lint:swift` PASS. Swift source не изменён. UI, capture, FFI и Windows CI не проверялись; сборка пустого ядра не доказывает G5.
- Вызваны и приняты: Codebase Scout (места и отсутствие клиента), Pattern Librarian (Node/Vitest без новых пакетов), External Researcher (первичные факты), Type Scaffolder (только тестовая схема), Visual Inspector (семь запретов запуска), Code Simplicity Reviewer (один проход логики; предупреждение исправлено).
- Локализации и production-реестры провайдеров не менялись; соответствующие механики не требовались. Generic workers не создавались. Использованы harmony-bootstrap, harmony-simplicity-examples и применимые Superpowers TDD, verification, debugging, review. Git/worktree не создавался: управляющий подтвердил отсутствие репозитория и выделил непересекающиеся области записи.
