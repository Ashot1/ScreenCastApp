## Подтверждённые опоры и пределы

Начальная база — существующее исследование в [decisions.md](../../decisions.md), разделы «Проверенные возможности macOS» и «Общий доступ к браузерам и сторонним приложениям». Ключевые выводы перепроверены 2026-10-18.

- Accessibility читает сведения, которые предоставляет конкретный интерфейс. Само наличие API не гарантирует дерево любого приложения или полный документ. [Apple: custom controls](https://developer.apple.com/library/archive/documentation/Accessibility/Conceptual/AccessibilityMacOSX/ImplementingAccessibilityforCustomControls.html).
- AXDocument и AXURL — возможные метаданные, но не обязательный достоверный URL активной вкладки для всех браузеров. Неопределённая или неоднозначная область должна блокировать чтение, если иначе можно захватить исключённое содержимое. Проверка перед отправкой также необходима. [Apple: AXDocument](https://developer.apple.com/documentation/applicationservices/kaxdocumentattribute), [AXURL](https://developer.apple.com/documentation/applicationservices/kaxurlattribute). Это проектное правило блокировки, не испытанная реализация.
- ScreenCaptureKit получает поверхность окна; изображение перекрытого окна не становится всем документом ниже прокрутки. OCR обрабатывает только полученное изображение. [Apple WWDC22](https://developer.apple.com/videos/play/wwdc2022/10155/), [Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest).
- В виртуальной таблице часть строк может отсутствовать в DOM; известный счётчик не даёт содержимое этих строк, а общее число может быть неизвестным. [W3C APG](https://www.w3.org/WAI/ARIA/apg/practices/grid-and-table-properties/).
- AX-действия нужно запрашивать у конкретного элемента. Таймаут AX не подтверждает отмену операции. Нельзя повторять действие, предполагая, что первое не произошло. [Apple: AXUIElementPerformAction](https://developer.apple.com/documentation/applicationservices/1462091-axuielementperformaction).
- SDK содержит отдельные no-prompt проверки для Accessibility, screen capture, слушания и отправки событий. Проверка слушания не подтверждает право отправлять события. Для этой стадии право отправки не запрашивалось и его статус не проверялся. [Apple: AX trust](https://developer.apple.com/documentation/applicationservices/1460720-axisprocesstrusted), [capture preflight](https://developer.apple.com/documentation/coregraphics/cgpreflightscreencaptureaccess()), [listen preflight](https://developer.apple.com/documentation/coregraphics/cgpreflightlisteneventaccess()).

Локально дополнительно прочитаны AXUIElement.h, AXAttributeConstants.h и соответствующие заголовки CoreGraphics SDK. В проекте нет готового runtime-чтения: macOS library target импортирует ScreenCaptureKit, но не реализует захват, Accessibility или остановку навигации.

## Основа следующей реальной пробы

Сохраняется согласованное разделение: Rust проверяет полномочия и состояние поиска, macOS получает факты ОС и исполняет разрешённые операции. В test-only v2 подготовлены AX reader/поиск, но их реальный охват и остановка ещё не проверены. Следующий шаг — предусмотренное предоставление прав конкретной v2 и испытание матрицы. Производственный runtime и общие манифесты не менялись.

Перед содержимым клиент должен определить приложение и выбранное окно, затем относящуюся к нему область сайта/документа. При отсутствии надёжной области — остановиться. При смене окна или вкладки нельзя использовать прежнее разрешение. Само совпадение заголовка или геометрии не является доказательством идентичности.

После разрешения области — ограниченное чтение AX и/или изображения выбранного окна. Фиксировать проверенную область, потери и недоступные части. Навигация допустима только для нового явного поиска; проверять полномочия и пользовательское вмешательство перед каждым следующим шагом, а завершение уже отправленного действия учитывать отдельно. Этот контур требует реальной проверки гонок; документация не даёт атомарной операции «проверить ввод и выполнить действие».

Матрица должна включать настоящее несохранённое поле Jira с безличным маркером, а не копию редактора. Право менять/сохранять реальные задачи не предполагается. Тестовые данные не должны уходить в облако; проверку запрета отправки можно проводить локально на границе будущего клиента.

## Решение, необходимое от управляющего

Нужны предусмотренные системные разрешения **новой сборке v2**, реальная проверка её LaunchServices/TCC-контекста и disposable Jira target по протоколу. Затем проверить весь reader/поиск и матрицу, особенно доступность принадлежности текстовых узлов, широкий охват и строгую остановку. Эти границы ещё не доказаны даже подготовленным кодом. Новые разрешения самостоятельно не выдавались. Все семь обязательных критериев и G2 остаются BLOCKED. Общий SwiftPM-check прежнего этапа был остановлен на `sandbox_apply`; итоговую общую проверку продолжения выполняет управляющий.

Отказ обратного `send_message_to_thread` сохранён; повторов и обходов нет. Управляющий подтвердил чтение обычных результатов в этом чате и отвечает сюда. Настоящий блокер передаётся обычным финалом.
