# Матрица 03 — пробы заблокированы до чтения

Дата: 2026-10-18. Все строки ниже — **BLOCKED**, не выполненные UI-тесты. Предпосылка: текущий процесс не имеет Accessibility, screen capture и listenEvents; [реальная проба](preflight.txt). Переданная v1 сохранена; отдельно подготовлены AX reader, ограниченный поиск, Stop и безличный fixture в [v2](../../../../../tests/feasibility/03-native/content-probe/protocol.md). Её [фактические результаты проверок](v2-verification.txt) подтверждают сборку/отказы/offline policy, но не реальные строки матрицы. Матрица описывает необходимое продолжение и не доказывает функциональность.

| Случай | Цели | Воспроизводимое действие после подготовки клиента | Требуемое наблюдение |
| --- | --- | --- | --- |
| Видимый текст | Chrome 155.0.8059.40, Safari 27.0, Aside 1.0.928.1; TextEdit 1.21 | Открыть только безличный тестовый документ с уникальным видимым маркером; определить область до чтения | Реальный маркер и фрагмент привязаны к текущему окну/источнику; известны права и метод чтения |
| Вне текущего экрана | Те же браузеры; TextEdit и Preview 11.0 | Длинный документ с другим маркером ниже экрана; сначала читать без навигации, затем по явному поиску прокрутить | Различаются текст, доступный через AX без прокрутки, и прочитанная после прокрутки часть; изображение не выдано за полный документ |
| Виртуальный/частично загруженный | Те же браузеры | Тестовая таблица с отсутствующими в DOM строками и известным/неизвестным rowcount; искать отсутствующий в текущей порции маркер | Неполнота фиксируется; счётчик не принят за прочитанные строки |
| Закрытая область | Браузеры; защищённое/закрытое представление native app | Использовать только специально подготовленную безличную закрытую область; не обходить защиту | Невозможность чтения отличается от отсутствия цели; доступ не расширяется |
| Несохранённый Jira | Настоящая разрешённая Jira test page в браузере | В disposable редакторе набрать безличный уникальный маркер, не сохранять задачу; прочитать текущий UI и привязать фрагмент | Доказательство именно несохранённого текста, окно/вкладка/фрагмент; REST сохранённой задачи не считается |
| Исключённое приложение | Тестовый native app | Исключить bundle ID в клиенте; начать наблюдение | Ни текст, ни изображение не прочитаны и не переданы |
| Исключённый сайт | Браузеры | Разрешённая и исключённая тестовые вкладки; смена вкладки до чтения и между чтением/подготовкой передачи | Старое разрешение недействительно; исключённый текст не читается/не отправляется |
| Исключённая папка | TextEdit/Preview; browser file URL | Разрешённые и исключённые безличные документы; смена окна | Путь определяется до чтения; смена окна инвалидирует прежнюю область |
| Источник неизвестен | Окно без надёжных URL/AXDocument | Запросить только необходимые метаданные, не извлекать текст | Безопасная блокировка чтения и передачи с явной причиной |
| Разрешённый scroll/expand | Браузеры; native раскрываемый документ | Новый явный поиск; отдельно прокрутка и раскрытие безопасного раздела | Поддерживаемые действия дают новый прочитанный участок; данные и формы не изменены |
| Пользовательский ввод | Каждая цель, поддержавшая поиск | Между шагами поиска начать ввод в целевом окне | Следующий шаг не отправлен; исполненный ранее отслежен до завершения; продолжения без нового запроса нет |
| Кнопка остановки | Те же цели | Между шагами нажать Stop тестового клиента | Следующий шаг запрещён; восстановление права/сети не продолжает старый поиск |
| Пассивное наблюдение | Все проверяемые цели | Запустить только чтение; сравнить фокус, scroll, раскрытие и данные до/после | Окно/данные не меняются; отсутствие навигационного вызова проверяется наблюдаемым состоянием |
| Отзыв разрешений | Работающий тестовый клиент | Отдельно отозвать каждый ранее выданный системный доступ предусмотренным способом | Соответствующая операция останавливается; новые чтения/шаги запрещены, старые данные не отправляются |
| Классы результата | Все доступные методы | Найденный маркер; гарантированно отсутствующий в полностью проверенной ограниченной области; недогруженная область; отказ права | Четыре разные формулировки: найдено; нет в проверенной области; неполно; невозможно прочитать |

Перечень целей нужен для разнообразия испытаний. Успешные результаты нескольких приложений не будут доказательством всех интерфейсов. Реальные версии, размеры окон, права, шаги и ограниченный охват нужно записывать при каждом выполнении. Сейчас размеры окон не измерялись и скриншоты не снимались.
