# 02: Чтение работающего Codex

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Подтвердить независимое чтение существующего чата и сохранённого завершения настоящего Codex без запуска или продолжения агента и без изменения его канонической истории. Результат закрывает G1 для конкретной проверенной версии.

**Blocked by:** None (can start immediately).

**Status:** done — G1 PASS для проверенной версии и области; [отчёт](../evidence/02-codex/report.md).

- [x] Зафиксированы версия Codex, вид чата и фактический интерфейс доступа. Инструменты текущего чата, публичная документация и одинаковое имя каталога не используются как доказательство доступа отдельного Ambient.
- [x] На разрешённой тестовой истории прочитаны исходный промпт, точная ссылка, доступный план и сохранённое завершение хода; устойчиво различаются чаты и ходы.
- [x] Наблюдался переход действительно работающего хода к завершённому, измерена задержка появления сохранённых данных. Отсутствие агента в отдельном процессе и изменение времени файла не приняты за доказательство завершения.
- [x] Проверено отсутствие запуска/продолжения агента и изменения канонической истории. Побочные изменения служебного хранилища проверены отдельно; запуск второго app-server на пользовательском профиле не считается по умолчанию доступом только на чтение.
- [x] Проверены неполная/запаздывающая история, недоступный чат, смена версии/формата и отсутствие доступа. Cloud-чаты и другие непроверенные виды не объявлены поддержанными.
- [x] Предоставлен воспроизводимый результат с выбранным способом чтения, границами совместимости и обнаружения завершений. Если подход требует записи или не подтверждает нужные данные, G1 остаётся незакрытым, задача 14 не разблокирована.
- [x] Личные чаты не создавались и не изменялись ради проверки без соответствующего запроса пользователя; в сохраняемых материалах нет личной истории.

Проверенная область: Desktop 26.1013.40934 (20770), движок 0.163.0-alpha.10.2, локальные `agent_created_thread`, только доступные записи явно выбранных JSONL. Реальное завершение замечено через 232.091 мс после времени события в одном замере. План проверен как обычный текст, ссылка — буквально. Cloud, полнота прежних страниц, другие виды/версии и UI-переход не объявлены проверенными. 11 тестов пробника и общие core/tooling-проверки прошли; Swift собран с `--disable-sandbox` после запрета вложенной песочницы, форматирование прошло. Никакой runtime-код источника пока не добавлен.

Дополнительная проверка вручную начатого управляющего чата также прошла: точные thread/turn/userMessage IDs и известная фраза человеческого ввода подтверждены независимым читателем. Для этой же версии и `paginated` точечно распознана `compacted` по официальной проекции видимой истории; контекст модели не восстанавливается, остальные неизвестные записи отвергаются.
