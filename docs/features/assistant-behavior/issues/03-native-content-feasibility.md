# 03: Общий доступ к приложениям

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Проверить общий механизм macOS для чтения приложений и браузеров, распознавания исключённых областей и поиска с разрешённой навигацией. Получить доказательства и пределы доступа для G2, а не список заранее зашитых интерфейсов.

**Blocked by:** None (can start immediately).

**Status:** blocked — v1 сохранена; отдельно собрана v2 с AX-чтением, ограниченным поиском и Stop, offline-проверки и ревью пройдены. Системных прав нет, реальные чтение/навигация/матрица не испытаны. G2 не пройден; [отчёт и реальные проверки](../evidence/03-native/report.md).

- [ ] Составлена и выполнена матрица разных браузеров и сторонних приложений: видимое содержимое, доступное содержимое вне экрана, частично загруженный/виртуальный документ и закрытая область. Зафиксированы версии, права и реальный охват.
- [ ] Отдельно проверено чтение несохранённого текста редактора Jira и привязка нужного фрагмента. API сохранённых задач не использован как доказательство доступа к черновику.
- [ ] Для исключений приложений, сайтов и папок проверено определение области до чтения/отправки, включая смену вкладки или окна. Неопределённый источник не позволяет отправить потенциально исключённое содержимое.
- [ ] На явно разрешённом тестовом поиске работают чтение, прокрутка и раскрытие доступного содержимого. Самостоятельный ввод пользователя в целевое окно и кнопка остановки запрещают следующий шаг, без автоматического продолжения.
- [ ] Наблюдение по инициативе помощника не меняет окно и исходные данные. Отзыв системного доступа останавливает соответствующую операцию.
- [ ] Результаты различают найденное, отсутствие в проверенной области, неполноту и невозможность чтения. Снимок окна не выдан за весь документ, а несколько удачных приложений — за доказательство всех возможных интерфейсов.
- [ ] Описан воспроизводимый общий подход для задач 06 и 21, с ограничениями и конкретными доказательствами. Невозможность обязательного случая передана на разбор подхода; требование широкого покрытия не заменено молча коротким списком браузеров.
