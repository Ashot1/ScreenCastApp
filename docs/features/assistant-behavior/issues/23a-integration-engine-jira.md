# 23A: Общий движок интеграций и Jira на нём

Spec: [ADR-020](../../../decisions/0020-integration-layer-contract.md), [ADR-019](../../../decisions/0019-unified-integrations.md), [ADR-017](../../../decisions/0017-selected-jira-issue.md). Decisions: [D58–D61](../decisions.md). Evidence: [карта повторов](../evidence/23-integration-layer-code-map.md).

**What to build:** Jira работает для пользователя как раньше — профиль, ключ, исключение сайта, чтение выбранной задачи, точный предпросмотр, атомарное сохранение и помощь 08B, — но уже через общий движок интеграций в Core, общий HTTP-транспорт, ABI интеграций v1, единого владельца секретов Swift с привязкой к экземпляру базы и общий каркас источника. GitHub продолжает работать без изменений на прежнем коде.

**Blocked by:** None — ADR-020 прошёл оба обзора; 12A/13A/08B приняты; активного владельца общей границы нет.

**Status:** accepted 20 октября 2026 — [приёмка](../../../../target/verification/orchestration/23a-parent-inspection.md), [handoff](../../../../target/verification/23a/handoff.txt). Контрольная сборка Ambient-integrations-23a.app.

- [x] Перед изменениями сняты эталоны текущего кода (JSON окна, предпросмотра, сохранённых метаданных, настроек, контекста модели 08B и цитаты для Jira и GitHub) и заморожена fixture схемы 10.
- [x] Схема 11: профили, исключения и метаданные интеграций, строка идентичности базы (`randomblob(16)`); таблицы Jira удалены; схема 10 отклоняется только для чтения без записи, миграции и сброса, включая WAL; проверка при открытии по ADR-020, включая ровно одну строку идентичности.
- [x] Общий движок Core по ADR-020: профили (дубликат и неизменность `scope`, `config`), замена/отзыв/удаление ключа, исключения с ABA, 401 точного поколения, пауза с единым правилом слияния, одна операция на интеграцию с каноническим допуском, общий пролог приёма, пределы и резерв последнего запроса, окно/предпросмотр/атомарное сохранение, `cancel_all_reads` вместо четырёх перечислений отмены.
- [x] Адаптер Jira реализует интерфейс ADR-020 без ветвления по виду внутри движка; предметная семантика ADR-017 (якорь ID, финальный GET, комментарии и хвост истории, ADF, связи, partial/missing/null/empty, 403/404/429/503) сохранена.
- [x] Основание 08B `Integration` с явным видом для Jira; GitHub — прежний вариант до 23B; `same_identity` с прежними полями Jira; контекст модели побайтно прежний; цитата `integration: {kind, metadata}` для Jira, `github` — до 23B.
- [x] Один HTTP-транспорт интеграций в providers; Jira использует `basic_auth`; реестр Jira — через Endpoint Registry Mechanic; ChatGPT-транспорт не тронут.
- [x] `ambient_integration.h` v1 заменяет `ambient_jira.h`: экспорты по виду, по профилю и по ID операции, две строки секрета, одна карта отмены без lock Store, цикл dispatch завершается отказом Core; GitHub1 и memory3/auth1/source1/Codex1/model4 не меняются; module map приложения согласован.
- [x] Swift: один владелец секретов (service `dev.ambient.foundation.integrations`, account `<экземпляр>/<профиль>`, Codable с явными `CodingKeys`, проверка вида, размера, экземпляра, профиля и поколения), общий каркас операции/модели/вида с защитой от устаревших ответов; Jira-специфичные разбор и поля сохранены; EN/RU через Localization Mechanic.
- [x] Эталоны Jira совпадают побайтно, кроме названных изменений; эталоны GitHub не изменились. Перенесены все 22 сценария `jira_source.rs`; общие наборы зелёные; новые тесты ADR-020 для 23A (ключ другой базы, вторая пауза, форма секрета, отказ Core после `max_requests`, сосуществование окон GitHub и Jira, ID другого вида) проходят.
- [x] Пройдены обязательные специалисты, TDD, Code Simplicity Review; `yarn verify`, feature Swift с test-support, all-features Clippy, сборка приложения, strict/deep подписи, аудит экспортов и Mach-O копией скрипта в `target/verification/23a/`, хэши исходников; все 210 файлов 15 контрольных сборок совпадают с `23a-checkpoints-baseline.json`.
- [x] Обновлены README модулей; нужные правки общих документов перечислены в handoff. Настоящие аккаунты, UI, TCC, модели и Jev не использовались; учёт 7 POST / 1021 known / 3 unknown не изменён.

**Не входит:** перевод GitHub (23B), переключатели (23C), Todoist, плагины/MCP, OAuth, Windows, настоящие подключения и полные 12/G6.
