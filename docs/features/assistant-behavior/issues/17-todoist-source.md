# 17: Todoist

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Добавить личные задачи Todoist к общему контексту работы, чтобы предложения учитывали их вместе с другими делами без изменения исходного списка.

**Blocked by (полная приёмка):** 07 — Несколько дел и связи между ними.

**Начало независимой части (D56):** после проверки используемой памяти и контракта источников 07; не требуется ждать модельной приёмки всего 07. Общие изменяемые контракты сначала завершает их владелец. Можно реализовать и проверить собственный реальный путь, но инициативные функции в остановленном приложении не работают. Полная приёмка сохраняет перечисленные зависимости и все критерии ниже; синтетический тест не заменяет настоящие подключения.

**Status:** ready-for-agent

- [ ] Подтверждены авторизация и право чтения задач, проектов, комментариев и необходимой доступной истории; проверены ограничения конкретного тарифа/аккаунта.
- [ ] Пагинация, диапазоны запросов и завершённые задачи читаются без объявления ограниченной выборки всей историей; повторное чтение не создаёт дубликатов дел.
- [ ] Личная задача связывается с намерением и доступными наблюдениями по основанию, сомнительная связь уточняется; завершённый элемент не закрывает более широкое дело автоматически.
- [ ] Нет создания, редактирования, завершения, удаления задач или записи комментариев. Источник не получает полномочий из собственного текста.
- [ ] Проверены недоступность, квоты, отзыв прав, пауза, исключения и удаление памяти; ограничения видны и не подменены пустыми списками.
- [ ] Настоящее чтение приводит к предложению/молчанию через общий механизм; сохранены результаты G6 и границы доступной истории.
