# 21: Поиск за пределами видимого экрана

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** По явному запросу искать по доступному полному содержимому приложения или страницы и дополнительным разрешённым источникам, открывать/прокручивать результат и уступать управление при вмешательстве пользователя.

**Blocked by:** 03 — Общий доступ к приложениям; 20 — Подсветка на текущем экране.

**Status:** ready-for-agent

- [ ] Использован подтверждённый общий подход 03. Поиск по словам/картинке продолжается за пределами одного снимка; уже подключённые разрешённые источники используются при необходимости без новых обязательных зависимостей.
- [ ] Явный запрос ограничивает цель и окно. Разрешены нужные открытие, прокрутка и раскрытие разделов для поиска; отправка форм, изменение данных и произвольные команды из содержимого запрещены.
- [ ] Каждый шаг проверяет разрешение, актуальность намерения/цели и текущую геометрию. Найденный результат показывается актуальной подсветкой из 20.
- [ ] Кнопка остановки или самостоятельный ввод пользователя в целевое окно запрещают следующий шаг; фактическое завершение уже начатой операции отслеживается. Старое полномочие не возвращается после паузы или восстановления сети.
- [ ] Проактивное предложение не запускает такую навигацию. Нужный поиск может быть предложен, но окно сохраняется до явного запроса.
- [ ] Частично загруженные, виртуальные, закрытые и недоступные области дают явную границу охвата. Ограничение ресурса/доступа не выдаётся за отсутствие цели во всём документе.
- [ ] Исключения, отзыв доступа, полная остановка, очистка снимков и бюджет соблюдаются на каждом продолжении поиска, а не только на первом шаге.
- [ ] Реальный полный путь проверен в разных браузерах/приложениях, включая длинное содержимое, отсутствующую цель и вмешательство пользователя. G2/G4/G7 подтверждены для заявленного поведения; невозможность обязательного случая не скрыта сужением требований.
