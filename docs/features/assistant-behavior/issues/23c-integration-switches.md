# 23C: Переключатели встроенных интеграций

Spec: [ADR-020](../../../decisions/0020-integration-layer-contract.md). Decisions: [D60, D61](../decisions.md).

**What to build:** В настройках есть раздел «Интеграции» с переключателями для локальных проектов, Codex, GitHub и Jira. Выключение сразу останавливает чтение и использование сведений интеграции в помощи и очищает зависимые обсуждения; сведения остаются в памяти. Включение возвращает их использование без повторного чтения и ввода ключей; операции, начатые до выключения, не оживают.

**Blocked by:** [23B](23b-github-on-integration-engine.md) — принят оркестратором.

**Status:** accepted — принят оркестратором 20 октября 2026 ([приёмка](../../../../target/verification/orchestration/23c-parent-inspection.md), [handoff](../../../../target/verification/23c/handoff.txt)). Свежий yarn verify 8/254/79; контрольная сборка Ambient-switches-23c.app.

- [x] Схема 13: таблица переключателей с ровно четырьмя строками (все включены при создании); проверка при открытии; схема 12 отклоняется только для чтения; fixture схемы 12 заморожена.
- [x] Операция включения/выключения через `Store::change`; повторная установка того же значения — без изменений и без `clear_revoked`; экспорты переключателей в ABI интеграций v1.
- [x] Проверка «включено» в допуске, каждом шаге, приёме, окне, предпросмотре, сохранении и в начале `source_settings_fence` и `source_authorization_fence` для Git, Codex и интеграций; `invalidate_stale_source`/`invalidate_stale_codex` вызывают свои fence.
- [x] Выключение во время запроса помощи по локальным проектам или Codex не даёт сохранить ответ, и база затем открывается.
- [x] Изменения настроек, ключа или исключения во время выключения дают обычное устаревание после включения.
- [x] Раздел «Интеграции» в настройках; выключенная интеграция показывает состояние и не даёт читать; EN/RU через Localization Mechanic, чувствительная формулировка утверждена оркестратором.
- [x] Тесты ADR-020 для 23C проходят; полный набор проверок с новой базой checkpoints после 23B.

**Не входит:** переключатели плагинов (отдельная спецификация), Todoist, Windows, настоящие подключения.
