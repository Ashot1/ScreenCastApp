# 09: Возврат к незавершённому делу

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Возвращать пользователя к действительно незавершённой работе после закрытия карточки: один повтор через 30 минут и один на следующий рабочий день, без навязчивых серий и потери правил при перезапуске.

**Blocked by (полная приёмка):** 07 — Несколько дел и связи между ними.

**Начало независимой части (D56):** после проверки используемой памяти и контракта источников 07; не требуется ждать модельной приёмки всего 07. Общие изменяемые контракты сначала завершает их владелец. Можно реализовать и проверить собственный реальный путь, но инициативные функции в остановленном приложении не работают. Полная приёмка сохраняет перечисленные зависимости и все критерии ниже; синтетический тест не заменяет настоящие подключения.

**Status:** ready-for-agent

- [ ] Первое закрытие запускает один порядок повторов на дело. Закрытие других его карточек, обновление и повторное закрытие не сбрасывают сроки/счётчики.
- [ ] При отсутствии продолжения допускаются один повтор через 30 минут и один на следующей локальной дате при начале любой работы, без требования вернуться к исходному проекту.
- [ ] Один вход в macOS без рабочей активности не вызывает накопленную серию. Обнаружение начала работы проверено, без предположения о расписании будних дней.
- [ ] Продолжение/завершение дела отменяет устаревшие поводы; копирование промпта само по себе не считается продолжением. «Не актуально» прекращает напоминания, не меняя внешний статус.
- [ ] Видимое действие не дублируется; при срабатывании напоминания разные полезные действия остаются различимыми. После двух повторов неизменное состояние молчит, новая полезная информация отличается от повторного чтения.
- [ ] Сон, перезапуск, совпадение сроков и полная остановка не сбрасывают историю и не создают серию пропущенных уведомлений. После восстановления сначала проверяется актуальность.
- [ ] Правила проверены через общий цикл с управляемым временем и на настоящем возвращении к работе; в оболочке не возник второй планировщик.
