# 25B: Каркас главного окна

Spec: [ADR-023](../../../decisions/0023-ui-redesign-liquid-glass.md). Decisions: [D72–D78](../decisions.md). Evidence: [опись дизайна](../evidence/25-ui-design-inventory.md), [Liquid Glass](../evidence/25-liquid-glass-research.md), [опись интерфейса](../../../design/ui-inventory.md).

**What to build:** Главное окно на `NavigationSplitView` со стеклянной боковой панелью: «Предложения N», дела, «Завершённые», листание, настройки, капсула статуса; выбор дела через привязку от модели с прежним окном несохранённого. Содержимое дела пока прежнее, разделы подряд.

**Blocked by:** приёмка 25A.

**Status:** ready — 25A принята; исполнитель запускается оркестратором (D80)

- [ ] Перенос `AssistantView` в каркас (диалоги, проверки), `CaseSidebar`, `CaseDetailView` без изменений поведения.
- [ ] Привязка выбора по ADR-023 (`get`/`set`, раздел по `.onChange` корня); тест не нужен для привязки, но путь «Отмена» в окне несохранённого не меняет раздел.
- [ ] `Callout`, `StatusRing` (три статуса и «завершение», с символом), `PageControls` для рядов окна; пустые состояния — `ContentUnavailableView`.
- [ ] `.defaultSize` сцены под боковую панель; `.disabled(model.busy || model.closing)` покрывает боковую панель.
- [ ] Тест: деление на открытые и завершённые на границах страниц.
- [ ] Перечень проверок (`rg` из ADR-023) снят до и после; каждое перенесённое или исчезнувшее выражение объяснено в handoff.
- [ ] Сначала перенос без изменений с проверкой сборки, затем оформление.
- [ ] Новые строки EN/RU — через Localization Mechanic; чувствительные тексты утверждает оркестратор.
- [ ] `yarn verify`, `yarn lint:swift`, `yarn build:macos`, подписи, контрольные сборки по базе оркестратора; приложение Ambient с данными пользователя не запускается (D77).
- [ ] Обязательные специалисты, TDD для логики, Code Simplicity Review; изменения общих документов перечислены в handoff.

**Не входит:** вкладки дела; страница шага; лента; настройки. Точка просмотра для пользователя после приёмки (D77).
