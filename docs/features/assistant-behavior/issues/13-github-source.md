# 13: GitHub

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Связать PR, замечания ревьюеров и проверки GitHub с памятью о работе, чтобы предложения оставались полезными после ухода со страницы и учитывали настоящее намерение пользователя.

**Blocked by (полная приёмка):** 07 — Несколько дел и связи между ними.

**Начало независимой части (D56):** после проверки используемой памяти и контракта источников 07; не требуется ждать модельной приёмки всего 07. Общие изменяемые контракты сначала завершает их владелец. Можно реализовать и проверить собственный реальный путь, но инициативные функции в остановленном приложении не работают. Полная приёмка сохраняет перечисленные зависимости и все критерии ниже; синтетический тест не заменяет настоящие подключения.

**Status:** ready-for-agent

- [ ] Пользовательский доступ ограничен разрешёнными репозиториями и нужными категориями чтения; подтверждено чтение PR, ревью, комментариев и статусов проверок.
- [ ] Пагинация, обновления и ограниченность ленты событий учтены. Сам объект и его актуальность проверяются доступным способом; лента не объявляется полной или мгновенной историей.
- [ ] Замечания к собственному PR остаются связаны с незавершённым делом после ухода со страницы; разрешённый следующий результат — разбор, текст или промпт для пользователя.
- [ ] Чужое ревью не становится автоматически задачей исправить чужой код. Повторяющаяся ошибка может связываться с уже известной целью, например улучшением инструкций, общей логикой, без отдельного обработчика этого примера.
- [ ] Статус PR или успешный check не закрывает целое дело без основания. Устаревшее замечание, недоступная проверка и изменённый PR не выдаются за текущее подтверждённое состояние.
- [ ] Отзыв прав, квоты и недоступность отражены; пауза/исключения/удаление соблюдаются. Комментарии, PR, ветки и проверки не создаются и не изменяются.
- [ ] Реальный путь до предложения и отрицательные случаи проверены, результаты G6 сохранены; совместный пример забытых веток проверяется в итоговой приёмке с локальным источником.
