# 20: Подсветка на текущем экране

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Показывать актуальное место на экране по словесному запросу, картинке или инициативному предложению: ненавязчивая рамка помогает найти объект и не мешает работе.

**Blocked by (полная приёмка):** 05 — Локализация через Jev; 06 — Первый работающий путь помощника.

**Начало независимой части (D56):** подтверждённый результат 05 и нужная нативная основа 06 позволяют разрабатывать собственную границу геометрии/подсветки без ожидания несвязанных коннекторов. Непроверенный Jev и отсутствующие разрешения не подменяются имитацией. Полная приёмка требует полного 06.

**Status:** ready-for-agent

- [ ] Используется подтверждённый результат 05. Работают оба режима — явный запрос и проактивная подсветка; ни один не заменён другим.
- [ ] Снимок получен из разрешённой области, запрос и повтор проходят общий бюджет. Проверка присутствия цели обязательна: Box, высокая уверенность и неизменность снимка сами по себе не разрешают показ.
- [ ] Координаты корректно преобразуются с учётом масштаба, обрезки, экрана и окна. Изменение содержимого, геометрии, намерения или цели убирает недействительную подсветку и не применяет поздний ответ к новому месту.
- [ ] Рамка тонкая, без мешающей заливки/мигания, пропускает мышь и не крадёт фокус. Интерактивная карточка остаётся отдельной от прозрачной подсветки.
- [ ] Проактивный режим не двигает и не прокручивает рабочее окно. Наличие прямоугольника не обещает точный контур объекта.
- [ ] На несохранённом тестовом тексте показана опечатка и предложена правка, но исходное поле не меняется. Пример использует общие возможности анализа/локализации, без специальной ветки сценария.
- [ ] Пауза, отзыв доступа, исключение области и отмена запрещают дальнейший показ/отправку; временные снимки очищаются, уже оплаченная попытка учитывается.
- [ ] Проверены отсутствие/неоднозначность цели, русский запрос, текст/образец, несколько экранов, масштабирование, Spaces и полноэкранные приложения. Результаты закрывают экранную часть G4/G7 в заявленном охвате.
