# 24C: Локальные серверы для любых плагинов

Spec: [ADR-022](../../../decisions/0022-local-mcp-servers.md), [ADR-021](../../../decisions/0021-plugins-layer.md). Decisions: [D64, D69, D70](../decisions.md). Evidence: [plugins/MCP](../evidence/23-plugins-mcp-research.md).

**What to build:** Пользователь добавляет плагин, чей сервер — команда запуска на Mac (в том числе из кэша Codex, включая `npx -y`/`uvx`). При просмотре он видит:
- точную команду, аргументы и имена переменных окружения;
- честное предупреждение о правах программы и о коде, скачиваемом при запуске.

Затем он вводит значения переменных (они хранятся в Связке ключей), нажимает «Запустить и показать инструменты» и одобряет инструменты «только чтение». Во время помощи модель сама вызывает их. Сервер запускается при первом вызове и останавливается вместе с запросом; отмена, пауза и выключение его завершают. Без локальных плагинов помощь побайтно прежняя.

**Blocked by:** [24A](24a-plugins-mechanism.md) — принят оркестратором 21 октября 2026.

**Status:** accepted — принят оркестратором 21 октября 2026 ([приёмка](../../../../target/verification/orchestration/24c-parent-inspection.md), [handoff](../../../../target/verification/24c/handoff.txt)). Свежий yarn verify 8/301/85; контрольная сборка Ambient-local-servers-24c.app.

- [x] `ServerKind { Remote, Local }` с меткой `kind` в сохранённом пакете, `needs_key()`, `Target { Remote, Local }` в разрешении и обнаружении. Прежние плоские поля удалены; сохранённый пакет без `kind` даёт `UnsupportedSchema`.
- [x] Разбор локального сервера:
  - пределы `command`, аргументов и имён переменных;
  - запрещённые имена (`PATH`, `HOME`, `TMPDIR`, `DYLD_*`, `LD_*`);
  - запись с `url` и `command` одновременно отвергается;
  - команда из папки пакета и `cwd` — предупреждение и пропуск;
  - предупреждения о `${VAR}` и относительных путях;
  - один проверяющий конструктор для установки и открытия.
- [x] `local_host.rs` в providers:
  - один `LocalHost` на `dispatch` и на операцию обнаружения, карта `Live | Failed`, не больше 4 процессов;
  - ленивый запуск;
  - группа процессов;
  - очищенное окружение, фиксированный `PATH` с раскрытой домашней папкой, частные `HOME`/`TMPDIR`/рабочая папка;
  - stdout только у stdio;
  - хвост stderr 8 KiB без значений секретов;
  - остановка: закрытие stdin, SIGTERM, 300 ms, SIGKILL, лидер и группа по 2 s, затем «остановка не подтверждена»;
  - `rustix` с feature `process`.
- [x] Провод stdio:
  - запись и чтение через потоки с каналами;
  - ограничение строки во время чтения;
  - `Invalid` и завершение процесса при мусоре, слишком длинной строке и запросе к клиенту;
  - `initialize` один раз за запрос;
  - `Failed` → `Unavailable` без перезапуска.
- [x] SIGPIPE игнорируется в функции запуска macOS-приложения; `EPIPE` → `Unavailable`; тест Swift-хоста вызывает эту функцию.
- [x] Секрет `env(map)`:
  - хранится в параметризованном владельце секретов плагинов;
  - передаётся компактным JSON с отсортированными ключами ≤16 KiB;
  - `parse_env_map` отвергает повторы, лишние имена и значения вне ASCII 33…126 после разбора;
  - секреты никогда не попадают в аргументы.
- [x] Пределы: запуск и `initialize` до 30 s, запас Core 120 s при `list_first` локального сервера и 90 s для удалённого, обнаружение до 120 s с отменой.
- [x] C ABI:
  - модель v6 — корневая папка в `dispatch` и тестовом двойнике;
  - `ambient_plugin.h` v2 — описатель операции (`operation_begin/cancel/close`), `discover(op, root, plugin, server)`;
  - обе карты модулей; аудит экспортов.
- [x] macOS:
  - просмотр с полным честным текстом ADR-022 «Что показывает просмотр» для локальных серверов;
  - ввод значений переменных;
  - кнопка «Запустить и показать инструменты» с отменой и хвостом stderr при отказе;
  - окно настроек не повторяет обнаружение само;
  - удаление частной папки после удаления плагина;
  - EN/RU через Localization Mechanic, чувствительные строки утверждает оркестратор.
- [x] Тестовые серверы на каждый сценарий ADR-022 «Testing Decisions» (stdio, окружение, секреты, отмена во время вызова и запуска, несколько плагинов, обнаружение); эталон запроса без локальных плагинов побайтно прежний.
- [x] Ручная проверка приёмки на одном настоящем локальном сервере из кэша Codex (`npx` или `uvx`): холодный запуск, обнаружение, вызов, отмена. Результаты и время — в handoff для `docs/verification.md`. (В кэше Codex подходящего нет; по решению оркестратора — `uvx mcp-server-time@2026.10.19`.)
- [x] Специалисты, TDD, Code Simplicity Review, полный набор проверок с базой контрольных сборок после 24A; список изменений общих документов (ADR-022 «Документация»).

**Не входит:** `Managed`, сервер Google, установка через `uv`, loopback HTTP и вход OAuth (24B); песочница; пул серверов; уборка «сирот»; настраиваемый PATH; `sse`; Windows.
