# 05: Локализация через Jev

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Подтвердить возможность Jev находить цель на статическом изображении по словам или картинке и корректно отличать отсутствие цели. Проверить координаты, ограничения, оплату и данные для G4 до встраивания подсветки.

**Blocked by:** None (can start immediately).

**Status:** blocked — проверен бесплатный контракт; предоставление Jev API key, верхняя стоимость и условия аккаунта не подтверждены. Подготовительный клиент ограничен **$1 суммарно** на все задачи/волны/попытки/неурегулированные расходы; **$1.50** оставлены для проверок реального приложения и **$2.50** — личного использования, этот клиент к ним доступа не имеет. Общий остаток требует сверки. Реальные вызовы в этом обновлении запрещены. G4 не закрыт, задача 20 заблокирована. [Отчёт](../evidence/05-jev/report.md), [протокол](../../../../tests/feasibility/05-jev/protocol.md).

Офлайн-подготовка выполнена: настоящий test-only HTTP-клиент, dry-run/preflight и единый SQLite-журнал с атомарным резервом и предупреждением 80% ($0.80), включая новую попытку; 35 локальных тестов проходят. Ключ будущей пробы — `TYPESAFE_API_KEY`; настройки — `tests/feasibility/05-jev/live-settings.json` по безопасному примеру, журнал — `docs/features/assistant-behavior/evidence/05-jev/jev-tests.sqlite3`. Перед POST сохраняются причина/случай/модель/endpoint/верхний резерв; старые расходы и unknown не сбрасываются при понижении cap. Начальная платная проба только P-ru, последующие — лишь для конкретного непроверенного критерия. Настоящие настройки/журнал не создавались, живые критерии ниже не отмечены выполненными.

- [ ] Зафиксированы доступная версия/режим Jev, экспериментальный статус, требования запроса и реальные ограничения изображения/контекста. Локальные веса или готовый экранный компонент не предполагаются.
- [ ] Выполнены ограниченные бюджетом пробы по тексту, русскому описанию и изображению-образцу; включены отсутствующая, похожая и неоднозначная цель.
- [ ] Возвращённый Box не считается доказательством присутствия. Проверено отдельное основание наличия цели; при отсутствии или неопределённости безопасная подсветка не предлагается.
- [ ] Проверены система координат, изменение размера и обрезка отправленного изображения; известна связь результата с исходным снимком для дальнейшей нативной геометрии.
- [ ] Установлена верхняя стоимость запроса, проверены реальный usage/биллинг изображений, ошибки, повтор и неизвестный расход. Платные пробы не выходят за заранее заданный предел.
- [ ] Проверены условия передачи и хранения изображений у поставщика; временные локальные материалы удаляются после обработки, личные изображения не сохраняются в отчёте.
- [ ] Предоставлены воспроизводимые результаты, задержка, ошибки и пригодная конфигурация для задачи 20. Экспериментальный статус или неудачные пробы не скрыты; незакрытый G4 блокирует зависимую функцию.
