# 27H: Живая проверка фонового режима

Spec: [ADR-025](../../../decisions/0025-background-observation.md). Decisions: [D82, D86–D104](../decisions.md).

**What to build:** Проверка на Mac пользователя: разрешение и индикатор, цена цикла, задержка, отправка с изображением и выданный уровень, 429 и обрыв сети, рамка, пауза, остановка, перезапуск.

**Blocked by:** приёмка 27G. 27C, 27E и 27F уже приняты локально; это не заменяет живую проверку.

**Status:** blocked

- [ ] Первый живой запрос со снимком (перенесён из 27D) — с сессией пользователя, по его согласию.
- [ ] Каждый платный вызов записан в журнале попыток (D57).
- [ ] Отчёт с измерениями и ограничениями.

**Не входит:** оптимизация по итогам — отдельные задачи.

Подготовка без живых действий: [порядок ограниченной проверки и оставшиеся условия](../../../../target/verification/orchestration/27h-preparation.md). Согласие на разрешения, настоящую сессию и конкретное число запросов запрашивается после приёмки27G и готовой проверяемой сборки. Подготовка не является разрешением или выполнением27H.
