# 27E: `ObservationSession` — снимок, распознавание, цикл

Spec: [ADR-025](../../../decisions/0025-background-observation.md). Decisions: [D82, D86–D104](../decisions.md).

**What to build:** Новые файлы Swift: снимок дисплея с передним окном через `SCScreenshotManager` (без окон Ambient), Vision с прогревом, цикл с сигналами активности и отсевом повторов в ядре по ADR-025, передача кадров и отправка через координатор; запуск только в сборке с флагом (как ADR-024); `ModelPurpose` в Swift узнаёт наблюдение.

**Blocked by:** приёмка 27D (принята); подключение в делегате — после 26A (принята)

**Status:** implemented — локально принято оркестратором: проверки, сборки, аудит и независимая сверка hashes пройдены (D105/D106). Живой захват и UI — 27H.

- [x] Сначала ядро: повторный кадр соблюдает предел кольца 1 MiB (находка 27D, ADR-025 «Уточнения реализации 27D»); регрессионный тест Rust; отдельный коммит при приёмке.
- [x] Рамка: чтение `highlight` при смене версии и после отправки; показ и скрытие через `HighlightOverlay` из 27F (после её приёмки).
- [x] Шов `FrameSource` для тестов без TCC; тесты задержки и допуска кадра по ответу ядра. Повторный кадр всё равно обновляет снимок и рамки слов; отдельного Swift-пропуска по пикселям нет (ADR-025).
- [x] Состояния «подготовка» и «нужно разрешение».
- [x] TDD для логики; обязательные специалисты; Code Simplicity Review; изменения общих документов — списком в handoff.
- [x] `yarn verify`, Clippy со всеми признаками, аудит экспортов и подписей, контрольные сборки по базе оркестратора.

**Не входит:** интерфейс (27G).
