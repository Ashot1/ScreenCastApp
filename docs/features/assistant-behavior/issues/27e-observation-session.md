# 27E: `ObservationSession` — снимок, распознавание, цикл

Spec: [ADR-025](../../../decisions/0025-background-observation.md). Decisions: [D82, D86–D104](../decisions.md).

**What to build:** Новые файлы Swift: снимок дисплея с передним окном через `SCScreenshotManager` (без окон Ambient), Vision с прогревом, цикл с сигналами активности, пиксельная заслонка, передача кадров и отправка через координатор; запуск только в сборке с флагом (как ADR-024); `ModelPurpose` в Swift узнаёт наблюдение.

**Blocked by:** приёмка 27D (принята); подключение в делегате — после 26A (принята)

**Status:** ready — исполнитель запускается оркестратором (D102: параллельно с 26E и 27F, без общих файлов)

- [ ] Сначала ядро: повторный кадр соблюдает предел кольца 1 MiB (находка 27D, ADR-025 «Уточнения реализации 27D»); регрессионный тест Rust; отдельный коммит при приёмке.
- [ ] Рамка: чтение `highlight` при смене версии и после отправки; показ и скрытие через `HighlightOverlay` из 27F (после её приёмки).
- [ ] Шов `FrameSource` для тестов без TCC; тесты задержки и заслонки.
- [ ] Состояния «подготовка» и «нужно разрешение».
- [ ] TDD для логики; обязательные специалисты; Code Simplicity Review; изменения общих документов — списком в handoff.
- [ ] `yarn verify`, Clippy со всеми признаками, аудит экспортов и подписей, контрольные сборки по базе оркестратора.

**Не входит:** интерфейс (27G).
