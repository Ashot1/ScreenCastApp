# 08B: Постоянная лента и текущее обсуждение

Spec: [ADR-015](../../../decisions/0015-persistent-proposal-feed.md), [полная спецификация](../spec.md). Decisions: [решения](../decisions.md).

**What to build:** Сохранять все активные предложения по делу и необходимое текущее обсуждение между запусками. Показывать разные действия в одной краевой ленте и общей панели; обновлять прежние без дублей и повторного открытия закрытых. Продолжение текстом и голосом использует прежний точный preview и одну отправку.

**Blocked by:** локально принятые 08A и 10A; приёмка 14A с окончательным общим контрактом источников. Один исполнитель владеет связанной Core/ABI/provider/native частью. Реальные Fast/TCC не нужны для локальной реализации, но рабочий допуск не подменяется.

**Status:** implemented-local-pass — 20 октября 2026. Связанный Core–C–Swift путь по ADR-015 реализован и локально проверен. `yarn verify`:8 tooling/154 Rust/71 Swift; feature Swift:105 с настоящим packaged ASR на публичном WAV. All-features Clippy/build/signature PASS;12 checkpoint apps/138 files сохранены. Реальные UI/Fast и полная08 остаются открытыми.

- [x] Реальный путь от выбранной памяти через bounded HTTP/SSE до нескольких постоянных предложений и их общей native ленты работает на временной SQLite. Сохранённые объекты доступны после перезапуска.
- [x] Core владеет одним текущим обсуждением на дело. Generated proposal, атрибутированная пара и исходные Evidence/план не смешиваются; receipt/capability не сохраняются.
- [x] Полный ответ с прежними IDs обновляет существующие действия; новые получают ID Core; отсутствующие удаляются. Чужие/повторные IDs, ошибочные citations и неготовые шаги отклоняются. Разные действия с одинаковыми основаниями не сливаются.
