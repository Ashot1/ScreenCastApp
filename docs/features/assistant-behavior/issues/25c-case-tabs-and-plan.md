# 25C: Вкладки дела, план и отмена источников в модели

Spec: [ADR-023](../../../decisions/0023-ui-redesign-liquid-glass.md). Decisions: [D72–D78](../decisions.md). Evidence: [опись дизайна](../evidence/25-ui-design-inventory.md), [Liquid Glass](../evidence/25-liquid-glass-research.md), [опись интерфейса](../../../design/ui-inventory.md).

**What to build:** Дело открывается вкладками «План / Заметки / Связи / Источники / Помощь»; вкладка плана с заголовком, меню «⋯», «Следующим шагом», шагами со статусами и зависимостями. Отмена чтений источников переходит в модель и на корень: переход между вкладками не прерывает чтение (D76).

**Blocked by:** приёмка 25B.

**Status:** ready — 25B принята; исполнитель запускается оркестратором (D80)

- [ ] `CaseTab` — сегментный `Picker`, содержимое условно; вкладки «Заметки», «Связи», «Источники», «Помощь» пока показывают прежние разделы, редактор шага встроенный.
- [ ] Отмена источников: `didSet` у `snapshot` (ID и ревизия `selectedTask`) и `manualPause` вызывают `cancelSourceViews()`; на корне — `assistanceReady == false` и `.onDisappear` (по итогу R3); из экранов источников убраны их обработчики отмены.
- [ ] Вычисляемые свойства «следующий шаг» (первый `ready` без `completedAtUTC` на загруженной странице; скрыт, если `nextAfter != nil` и такого нет) и «ждёт шаг N» (только при загруженных страницах); готовность не выводится в Swift.
- [ ] Заголовок дела, точка статуса, меню «⋯» из существующих действий; `Pill`; `PageControls` в плане.
- [ ] Тесты: «следующий шаг» и граница страницы; «ждёт шаг N»; смена дела (ID/ревизия) и пауза отменяют все пять источников; открытие шага или редактора не меняет `selectedTask` и не отменяет.
- [ ] Перечень проверок (`rg` из ADR-023) снят до и после; каждое перенесённое или исчезнувшее выражение объяснено в handoff.
- [ ] Сначала перенос без изменений с проверкой сборки, затем оформление.
- [ ] Новые строки EN/RU — через Localization Mechanic; чувствительные тексты утверждает оркестратор.
- [ ] `yarn verify`, `yarn lint:swift`, `yarn build:macos`, подписи, контрольные сборки по базе оркестратора; приложение Ambient с данными пользователя не запускается (D77).
- [ ] Обязательные специалисты, TDD для логики, Code Simplicity Review; изменения общих документов перечислены в handoff.

**Не входит:** страница шага и редакторы (25D); новые вкладки заметок, связей, источников (25F).
