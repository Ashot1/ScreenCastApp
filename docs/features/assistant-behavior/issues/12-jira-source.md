# 12: Jira

Spec: `docs/features/assistant-behavior/spec.md`. Decisions: `docs/features/assistant-behavior/decisions.md`.

**What to build:** Подключить задачи, связи, комментарии и доступную историю Jira к общей памяти, чтобы обсуждения и текущая работа сопоставлялись с задачами без расширения объёма по ошибке.

**Blocked by (полная приёмка):** 07 — Несколько дел и связи между ними.

**Начало независимой части (D56):** после проверки используемой памяти и контракта источников 07; не требуется ждать модельной приёмки всего 07. Общие изменяемые контракты сначала завершает их владелец. Можно реализовать и проверить собственный реальный путь, но инициативные функции в остановленном приложении не работают. Полная приёмка сохраняет перечисленные зависимости и все критерии ниже; синтетический тест не заменяет настоящие подключения.

**Status:** ready-for-agent

- [ ] Подтверждены тип используемой Jira, подходящий способ авторизации и минимальные доступные права чтения; сведения о Jira Cloud не перенесены без проверки на другой вариант установки.
- [ ] На настоящем разрешённом источнике прочитаны задача, доступные зависимости/ссылки и обсуждение, включая пагинацию. Идентичность, источник, время и полнота переданы общей логике.
- [ ] Работа/обсуждение сопоставляются с задачей по основанию; неоднозначная связь уточняется и может быть исправлена. Предложение объединить работу или оставить отдельной не меняет Jira.
- [ ] Несохранённый текст редактора поступает через проверенный общий механизм доступа; API сохранённой задачи не выдаётся за текущее поле ввода. Правка остаётся предложением без автозамены.
- [ ] Проверены отсутствие прав, недоступная задача, квоты, неполная история и отзыв доступа. Ни один из этих случаев не означает, что задача или зависимость отсутствует.
- [ ] Нельзя создавать/изменять задачи, статусы, комментарии и связи. Исключения, остановка, очистка временных данных и запрет возвращения удалённой памяти применяются до записи/передачи результата.
- [ ] Подключение даёт настоящий путь чтение → память → предложение; зафиксированы результаты G6 и текущие ограничения без отдельного сценарного движка Jira.
