# 01: Облачный анализ через подписку ChatGPT

Spec: `docs/features/assistant-behavior/spec.md` (§7–8, G5). Decisions: `docs/features/assistant-behavior/decisions.md` (D52, D55).

**What to build:** Подтвердить официальный облачный маршрут через выбранную пользователем подписку ChatGPT: разрешённый текст/изображение → предложение с основанием либо молчание. Проверить собственный вход приложения, доступную модель, ограничения подписки и отсутствие дополнительных списаний. Для включённой квоты не требуется выдуманный USD-резерв. Результат — G5, не готовый нативный интерфейс или G7.

D52 запрещает отдельный платный OpenAI API, дополнительные оплачиваемые кредиты и fallback на них. Старый API-код удалён, прежние результаты сохранены как история. CLI-вход не переносится в Ambient. Node используется только в испытательном стенде; владельцы runtime, бюджета и native credentials остаются прежними.

- [ ] Зафиксированы поставщик, фактическая доступная модель/версия, режим, входы и ограничения. Запрос фиксирует `gpt-6-luna`, Fast (текущий wire `service_tier: priority`; две исторические попытки отправили `fast`) и reasoning effort low по умолчанию либо явный high; возвращённые model/tier/effort-метаданные отдельно записываются. Явное расхождение effort помечает конфигурацию как несовпадающую; это поле не доказывает внутренние рассуждения модели. Право аккаунта и Fast подтверждаются ответами SIWC, а не наличием CLI login или подготовленным запросом.
- [ ] На разрешённых синтетических данных проверены текст/изображение, предложение/молчание, безопасный отказ, незавершённый/неверный ответ. Структурная корректность отделена от смысловой. Локальный incomplete не выдан за наблюдение провайдера.
- [ ] Перед моделью подтверждено отсутствие дополнительных списаний: cap этого приложения <100% либо общий Allow apps to use credits OFF. Источник подтверждения указан как пользовательский; API-чтение такой настройки не выдумано. Настройки не включаются автоматически.
- [ ] Сохранён реальный usage и проверены ограничения подписки, обрыв и отмена. Неизвестное потребление не равно нулю и блокирует новую пробу до сверки. Нет автоматических повторов, платного API/credit fallback и собственного счётчика остатка общей подписки.
- [ ] Собственные токены защищены; CLI credentials не копируются. Описаны условия данных именно выбранного подключения, response storage/кэш/журналы и ограничения удаления. D55 защищает собственную сессию стенда через Keychain; её реальное сохранение/чтение и повторное использование нормальным CLI без браузера подтверждены управляющим. Production native-интеграция и реальный refresh ещё не проверены. Условия хранения/обучения SIWC остаются неподтверждёнными.
- [ ] Сохранены условия и результаты всех реальных проб, actual usage, задержка, ошибки и ограничения. Документальные/локальные проверки отделены от inference; вывод о модели — от общей полезности Ambient.
- [ ] Для 06 есть доказанная рабочая конфигурация. Неподтверждённая обязательная возможность явно блокирует её, без подмены требований. Нативная интеграция и G7 остаются в 06.
