# 26E: Лента в окне и у края по макету

Spec: [ADR-024](../../../decisions/0024-design-fidelity-pass.md); base [ADR-023](../../../decisions/0023-ui-redesign-liquid-glass.md). Decisions: [D83–D86](../decisions.md). Макет: `target/verification/design/ambient-design.pdf`.

**What to build:** Лента в окне и у края во всех состояниях карточек — по страницам 2, 12, 13; наполнение ленты для сверки.

**Blocked by:** приёмка 26D (принята)

**Status:** DONE_LOCAL / VISUAL_LIMITS_RECORDED — D107 код и проверки приняты локально: verify8/394/125, featureSwift181, normal/ordinaryVisual build+audit/signatures PASS; 294/12owned неизменны при проверках. Пользовательский снимок новой панели подтвердил компактную высоту D107 (932×352 px, `d107-edge-user-green.json`). Основные доступные экраны и empty пройдены. Остались явно ограниченные проверки: заполненная строка Источников, вид popup-меню (пункты подтверждены AX), состояния ответа/голоса со входом — пользовательские.

**Не входит:** настройки (26F); состояния со входом и запись голоса — только пользователь.

**Дополнение D107, 23 октября 2026:** пользователь согласовал высоту краевой панели по содержимому. Короткое сообщение/лента компактны; длинная лента ограничена прежним максимумом и доступным экраном, с прокруткой. Исключительная область того же исполнителя расширена на размер окна в `EdgeCardController` и его тесты. Остальные правила показа/скрытия, допуска, фокуса, ширины, выбора экрана и черновика не меняются. Нужны проверки роста и уменьшения содержимого, длинной ленты и ограниченного экрана; свежая сборка и повторная сверка затронутой панели.

При изменении высоты сохраняются текущий верхний край и горизонтальное положение панели с ограничением по `visibleFrame`; окно не переезжает к указателю. Измерение учитывает локальное раскрытие карточки и редактор ответа, а не только обновление модели.
