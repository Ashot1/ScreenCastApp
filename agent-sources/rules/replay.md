# Replay and fixtures

- Replay is deterministic core input/output verification; platform capture is tested separately on actual OS APIs.
- Fixtures use synthetic or consented sanitized data, explicit capture gaps and expected outcomes. Never commit raw personal screenshots, credentials or private messages.
- Record source, license/consent, schema version, time basis, geometry and expected decisions for every episode.
- Include fleeting alerts, app switches, unchanged-screen timers, budget exhaustion, overload, cancellation tails, helper crashes and multi-display transforms.
- A green replay does not establish model quality or live capture coverage. Keep human labels, baseline comparisons and timeout/failure counts explicit.
