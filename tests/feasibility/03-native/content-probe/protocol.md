# NativeContentProbeV2 — подготовленная нативная проба

Это test-only код для последующего испытания G2. Реальное чтение текста, навигация, Stop, отзыв прав, Jira и матрица разных приложений **не испытаны**. Результаты unit-тестов не заменяют эти случаи.

## Сборка и идентичность

Из `/Users/gojda/Projects/ScreenCastApp`:

```sh
bash tests/feasibility/03-native/content-probe/test.sh
bash tests/feasibility/03-native/content-probe/build.sh
```

Новая сборка находится только здесь:

```text
/Users/gojda/Projects/ScreenCastApp/tests/feasibility/03-native/content-probe/.scratch/NativeContentProbeV2.app
bundle ID: dev.ambient.feasibility.native-content-v2
executable SHA-256: ca51b855ac367423eaa41892a726ef5663aea53d7182c8344ac0a636f7b18e94
```

Старый `.build/NativeContentProbe.app` не перезаписан; его SHA-256 остался `33192207b1cd8f27f85d92d6640d2a9321d387a992b12f35d4e729d812b94649`. У v2 другой bundle ID и другая подпись. Будущие системные разрешения понадобятся **конкретной сборке v2**; выдача прав v1 не считается выдачей прав v2. Пересборка ad-hoc клиента также не гарантирует сохранение прав. Готовый v2 bundle скрипт повторно не перезаписывает.

Все компиляции, кэши и тестовые бинарники v2 лежат в собственной `.scratch`. Общие SwiftPM scratch-path, runtime, manifests и настройки системы не меняются.

## Запуск без запроса прав

```sh
tests/feasibility/03-native/content-probe/.scratch/NativeContentProbeV2.app/Contents/MacOS/NativeContentProbeV2 --preflight
```

Фактически получены три `false` и exit 2. Это прямой запуск бинарника: LaunchServices и GUI-привязка TCC **для v2** не проверялись. Не переносить на него успешный LaunchServices-запуск v1.

```sh
tests/feasibility/03-native/content-probe/.scratch/NativeContentProbeV2.app/Contents/MacOS/NativeContentProbeV2 \
  --request tests/feasibility/03-native/content-probe/request.example.json
```

Шаблон содержит заведомо невыбранный PID и только безличные данные. Сейчас получен `permission-denied`, exit 2: AX-чтение и UI поиска не запускаются. Для настоящей будущей пробы нужно явно указать PID разрешённого тестового приложения, точный bundle ID и URL документа, а также реальные исключения. Открывать только disposable материалы. Не подставлять случайное окно пользователя.

`mode: read` делает одну попытку чтения без навигации. `mode: search` требует непустой `query` и `navigation: scrollDown` либо `expand`, а также фактически доступные Accessibility и Input Monitoring. Будущий GUI-запуск через `open -g -n -W` использует этот **v2** bundle и `--args --request <absolute request path>`, с собственными stdout/stderr. Разрешения приложение не запрашивает и не меняет.

## Что подготовлено

- Проверка PID, bundle ID, времени запуска процесса, текущего приложения, AX focused window и источника. Приложение из исключений блокируется до AX-запросов. Адрес/путь читается до текста; неизвестный источник блокируется.
- Отдельная проверка `AXDocument` **самого текстового узла**. Адрес окна не наследуется дочерними областями: split panes и вложенные документы могут иметь другую принадлежность. Узел без такого атрибута пропускается до чтения текста. Многие интерфейсы могут его не предоставлять; это серьёзное непроверенное ограничение охвата, а не доказанная поддержка всех приложений.
- До 64 посещённых/ожидающих узлов и 64 фрагментов; сохраняемый текст — до 8192 UTF-8 байт, глубина до 8. Для редактируемого текста запрашивается ограниченный AX-диапазон, для статического — предоставляемое AX-значение. Потери отмечаются. Бюджет 1,5 секунды проверяется между узлами; синхронный AX-вызов и завершающая проверка могут увеличить общую длительность. AX IPC не гарантирует ограничение временного выделения памяти у ОС/источника.
- Защищённые текстовые поля пропускаются. Неизвестные, неподдерживаемые и ошибочные участки дают неполноту. Сохраняемый текст живёт только в памяти одной итерации; накопления истории нет.
- Геометрия AX в координатах рабочего стола, с проверкой CF-типа и чисел. `windowClippedAXRect` — только пересечение рамки элемента с рамкой окна, а не доказательство видимости текста, положения слова или отсутствия перекрытия. Всегда выводится `visibility=unknown`; преобразование в пиксели скриншота не реализовано.
- Поиск может сделать до четырёх нативных действий и до пяти чтений. Разрешены только поддерживаемый increment вертикальной AX-полосы прокрутки и раскрытие подтверждённого disclosure-элемента через AXExpanded. Другие действия и ввод отсутствуют. Перед действием проверяются источник самого элемента, окно, геометрия и разрешение на следующий шаг.
- Некрадущая фокус тестовая панель имеет Stop; остановка защёлкивается, поздний шаг не возобновляет старый запрос. Перед/после шага сравниваются HID-счётчики клавиатуры, мыши, scroll и tablet; изменение запрещает следующий наблюдаемый шаг. Это консервативный polling-сигнал, **не атомарная гарантия G2**. Автоповтор клавиш и другие ограничения API ещё требуют настоящей проверки; уже отправленный AX-вызов отменённым не считается.
- В stdout только безопасные статусы, счётчики, ограничения и до восьми рамок совпадений. Текст, запрос, URL, заголовки и снимки не печатаются; сеть и облачные клиенты отсутствуют. Отсутствие совпадения относится только к прочитанным фрагментам. Пустое чтение — `unreadable`.

Коды: `0` — ограниченная операция завершилась; `2` — нет права/поиск остановлен; `3` — неподтверждённая цель, источник или возможность; `4` — ошибка AX; `64` — неверный запрос. Ни exit 0, ни найденный маркер не подтверждают весь G2.

## Что осталось

После предусмотренного предоставления прав именно v2 — выполнить [матрицу](../../../../docs/features/assistant-behavior/evidence/03-native/matrix.md) и [протокол настоящего Jira draft](../protocol.md). Проверить реальные узлы и их принадлежность, несохранённый текст и привязку фрагмента, область вне экрана/виртуализацию, смену вкладок, исключения, отзыв прав, Stop и ввод человека. Без этих доказательств широкий охват и строгую остановку считать подтверждёнными нельзя.
