# Cloud feasibility probe

Node 22 tooling only. The production assistant remains Rust/native.

- `probe.mjs`: own loopback sign-in, per-run human credit-setting confirmation, visible-model discovery and exactly one synthetic Responses POST. It requests `gpt-6-luna`, Fast and low reasoning effort by default (high is explicit). Fast uses canonical wire ID `service_tier: priority`; payload, plan and new requested_configuration records contain that exact sent value, while confirmation/CLI keep the Fast label. Returned fast/priority remain accepted as Fast; a returned configuration mismatch is not success. The full model catalog is bounded to 2 MiB of decoded bytes before strict UTF-8/JSON parsing; overflow cancels the reader and prevents POST even on HTTP errors. Auth keeps its separate 512 KiB bound. POST alone sends Accept: text/event-stream; normalized absent/SSE MIME uses strict event parsing, while explicit other MIME fails. Closed response_metadata records received HTTP status, media type, body presence and bounded read outcome/count across success/error paths. HTTP/non-SSE rejection diagnostics accumulate at most 16 KiB of decoded bytes and add only fixed response shape, allowlisted provider code and exact request-field parameter; body read/cancel failures retain known sent dispatch and unknown usage. Fixed diagnostics distinguish failures before/after dispatch; unknown usage blocks later runs.
- `auth.mjs`: openid-client code/refresh grants with signature checks, one verified registration and one reusable session. Save precedes model discovery; an expiring session is deleted from Keychain before one refresh, and its replacement is saved before use. Storage/refresh failure stops the current run without browser fallback.
- `keychain.mjs`: bounded private stdin/stdout transport to a stable prebuilt Swift helper. Tokens never enter argv, environment, plaintext temporary files or logs. Timeout/cancellation waits for child closure before the probe lock is released.
- [`native-keychain/`](native-keychain/README.md): macOS Security storage adapter and actual isolated temporary-Keychain tests. Build the release helper once after changing its sources; the probe never compiles it during sign-in. macOS may ask for Keychain access.
- `response.mjs`: bounded SSE parsing; canonical completed items (eight, 64 KiB total JSON in RAM) reconstruct explicitly empty terminal output after response.completed. Nonempty terminal is authoritative but observed content conflicts fail. Existing proposal/usage/configuration checks remain; delta text has no second accumulator/validator. Closed output_source/validation/event metadata contain no raw item values in diagnosticMode.
- `cases.json`, `response-schema.json`, `synthetic.png`: synthetic inputs and expected evaluation; `incomplete` is local-only.
- `package-lock.json`: isolated pinned tooling dependencies; `jose` directly serves test signing.
